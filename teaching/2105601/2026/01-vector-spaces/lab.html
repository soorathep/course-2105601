Steam methane reforming: independent reactions and reconciled flows

About 40 minutes. Works in class or on your own, on a laptop or a phone. Nothing to install; a calculator helps.

How this lab works

A steam reformer converts methane and steam into hydrogen. You find how many independent reactions the five species allow, test the three reactions written in textbooks, then reconcile a set of outlet measurements that do not close the element balances, and write a test that finds a biased meter. Plan about 20 minutes for the guided steps and 20 for the code. Write each prediction before you look; the next step stays locked until you do. Numbers are accepted within about 1% (or the stated tolerance); after two tries the expected value is shown.

What runs where. The RUN steps show results that subspace_lab.py computed in advance. The CHANGE step computes a rank in JavaScript on this page. The CODE step runs your Python in this page (Pyodide, with NumPy and SciPy; the first run loads it, about 20 seconds). Nothing is installed on your device. To run the Python yourself, open the slides and press D on a slide marked “D · Python” (it runs in your browser), or run subspace_lab.py in desktop Python.
