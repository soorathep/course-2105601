Bifurcation and multiplicity: derivations

Five derivations for Session 5. About two hours; do them before the midterm.

How to use this set

Work each problem on paper before you look at the final answer. The final answer lets you check your result; it does not show the derivation, which is the point of the exercise. These problems are in the style of the midterm.

Problem 1 · The S-curve and its folds

For the scaled cooled CSTR, dx1/dt = −x1 + Da(1 − x1)ex₂, dx2/dt = −(1 + β)x2 + B Da(1 − x1)ex₂, derive the closed form Da(x2) of the steady states and the fold condition. Evaluate both folds (x2 and Da) for B = 14, β = 2.

Final answer. Da = c x2e−x₂/(1 − c x2), c = (1 + β)/B; folds at c x2² − x2 + 1 = 0. For B = 14, β = 2: x2 = 1.451 (Da = 0.1057, ignition) and x2 = 3.215 (Da = 0.0889, extinction).

Problem 2 · Trace and determinant on the branch

Show that on the steady-state branch tr J = −1/(1 − x1) − (1 + β) + Bx1 and det J = [(1 + β) − Bx1(1 − x1)]/(1 − x1). Then show that det J = 0 gives the same folds as dDa/dx2 = 0.

Final answer. Use Da(1 − x1)ex₂ = x1; with x1 = c x2, (1 + β) − Bx1(1 − x1) = (1 + β)(1 − x2 + c x2²), which vanishes exactly at the fold quadratic.

Problem 3 · A Hopf point in the Brusselator

For dx/dt = a − (b + 1)x + x²y, dy/dt = bx − x²y with a, b > 0, find the steady state, its Jacobian, and the value of b at which a Hopf bifurcation occurs. Give the period of the small oscillations there.

Final answer. Steady state (a, b/a); tr J = b − 1 − a², det J = a²; Hopf at b = 1 + a², period 2π/a.

Problem 4 · Why pseudo-arclength passes a fold

At a simple fold, J = ∂F/∂x has a one-dimensional null space spanned by φ, and FDa is not in the range of J. Show that the tangent is t = (φ, 0) and that the bordered matrix [J FDa; tᵀ] is nonsingular, while J alone is singular.

Final answer. [J FDa] has rank n with null vector (φ, 0), so t = (φ, 0). If [J FDa; tᵀ](v, μ) = 0, then Jv + μFDa = 0 forces μ = 0 (FDa not in the range), so v ∝ φ, and tᵀ(v, 0) = 0 forces v = 0.

Problem 5 · A subcritical Hopf bifurcation

The amplitude equation ṙ = μr + r³ − r⁵ describes a subcritical Hopf bifurcation. Find all limit cycles, their stability, and the range of μ in which a stable steady state coexists with a stable cycle.

Final answer. r² = [1 ± √(1 + 4μ)]/2: the larger root is a stable cycle and the smaller an unstable one; they exist for −1/4 < μ (the unstable one only for μ < 0). Bistability (hysteresis) for −1/4 < μ < 0.
